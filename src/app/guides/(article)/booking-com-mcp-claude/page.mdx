# Booking.com MCP in Claude

<GuideDates published="2026-11-07" updated="2026-11-07" />

**Short answer:** Add `https://hotels.flightpowers.com/mcp` to Claude as a custom connector,
sign in with Google, and ask for a hotel. Claude gets four tools that read live Booking.com
availability and rates when you ask: search a destination, price one hotel by name, search
Airbnb, and compare the two. Your first 10 searches each day are free, with no key and no card.
For more, paste your own RapidAPI key once: PRO is ${PRO.priceMonthly} a month for{' '}
{PRO.quota.toLocaleString('en-US')} hotel searches.

## What this server is

It is mine: FlightPowers runs a hosted MCP server, so nothing installs on your machine. Its
tools read Booking.com's live availability and rates at the moment Claude asks and return each
property's stay total, price per night, review score, room type, location, coordinates and a
Booking.com link. It reads rates; it does not make reservations, and FlightPowers is not
affiliated with Booking.com. The same server is behind the [hotel MCP page](/mcp/booking-hotels),
which has the full parameter list.

## What you need

- <a href="https://claude.ai/" rel="noopener">Claude</a> on the web or the desktop app, or Claude Code
- A Google account for the sign-in
- Optional, past 10 searches a day: a RapidAPI key subscribed to the <a href={rapidApiPricingUrl('hotels', 'guide', 'booking-mcp-claude-needs')} rel="noopener">Booking Live API</a>. BASIC is free for {BASIC.quota} searches a month (enough to check the key works), PRO is ${PRO.priceMonthly} for {PRO.quota.toLocaleString('en-US')}.

## Add it to Claude

One click opens Claude's "Add custom connector" screen with the name and the URL filled in:

<AddToClientButtons server="hotels" clients={['claude']} claudeLabel="Add hotels to Claude" claudeHint={false} />

{CLAUDE_AUTH_HINT}

By hand: in Claude on the web or the desktop app, open Customize → Connectors → + Add → Add
custom connector. Paste `https://hotels.flightpowers.com/mcp`, press Continue, choose ‘Sign in
when needed’ (not the pre-selected ‘No sign-in’), then Add, and sign in with Google when Claude
asks. Flights are a second connector, `https://flights.flightpowers.com/mcp`, set up the same
way ([the Google Flights MCP guide](/guides/google-flights-mcp-claude)); the 10 free searches a
day are shared by both.

## Add it to Claude Code

```bash
claude mcp add --transport http hotels https://hotels.flightpowers.com/mcp
```

Then open `/mcp` in a session and sign in. `claude mcp list` prints `✔ Connected` when it
worked and `! Needs authentication` when the sign-in has not happened yet. To share it with a
project, put it in `.mcp.json` at the project root (nothing secret in it):

```json
{
  "mcpServers": {
    "hotels": { "type": "http", "url": "https://hotels.flightpowers.com/mcp" }
  }
}
```

## The four tools

**search_hotels**: Live Booking.com search for a destination written the way a person would
write it ("Rome", "Tokyo Shibuya") and a check-in and check-out date. Returns 10 properties by
default with the cheapest always among them; `limit` asks for more or fewer. Filters:
`budget_per_night`, `adults`, `children`, `currency`, and `filters` such as
`free_cancellation` or `breakfast_included` (an unknown filter name is refused with the list of
valid ones, never silently ignored).

**find_hotel_by_name**: One named property, the way a person would type it (add the city when a
chain has many). No property id needed; the server resolves the name. Good for "is my hotel
cheaper next week" and for a rate calendar of one hotel.

**search_airbnb**: Live Airbnb stays for a destination and dates, read from Airbnb's public
search page: stay total, price per night, rating out of 5, room type, bedrooms, beds, baths and
an Airbnb link. It needs its own Airbnb Live API subscription on the same RapidAPI key (PRO is
${AIRBNB_PRO.priceMonthly} for {AIRBNB_PRO.quota.toLocaleString('en-US')}); the 10 free sign-in
searches do not cover it.

**compare_hotel_rates**: The same stay on Booking.com and Airbnb, one row per source: the
cheapest and the median stay total and how many places were found. Ratings are out of 10 on
Booking.com and out of 5 on Airbnb, and `taxes_included` is null on Airbnb because its page does
not say. It runs on your own key, one request per source on that source's subscription.

## More prompts to try

**A rate calendar for one hotel.** "Price Hotel Artemide in Rome for 3 nights, for every
check-in date in April." `find_hotel_by_name` takes `checkin_date_from`, `checkin_date_to` and
`nights` and prices one stay per date in a single call. Each stay is one search, so a month of
dates runs on your own key, not on the 10 free a day.

**The rate a shopper in another country sees.** "Price the Rixos Sungate in Antalya for May 5
to 10 as seen from the US, Germany and Israel." `price_as_seen_from` takes a two-letter country
code. Gaps between countries are real but usually modest and depend on the property, so call
each country a few times before you call it a gap.

**A budget and filters.** "Hotels in Lisbon, March 9 to 12, two adults, under 150 euros a
night, free cancellation."

**Booking.com against Airbnb.** "Compare Booking.com and Airbnb for Lisbon, March 5 to 8, two
adults, in dollars." (Needs both subscriptions on your key.)

## Going past 10 searches a day

Paste your RapidAPI key once: on the page that opens when you sign in, or later at
`https://hotels.flightpowers.com/connect` with the same Google account. It is encrypted before it
is stored, only its last four characters are ever shown again, and searches then meter against
your own subscription. Disconnect on the connect page deletes it.

For `claude -p` in a cron job, CI, or a client with no sign-in button, send the key in a header
instead, same URL:

```json
{
  "mcpServers": {
    "hotels": {
      "type": "http",
      "url": "https://hotels.flightpowers.com/mcp",
      "headers": { "x-rapidapi-key": "YOUR_RAPIDAPI_KEY" }
    }
  }
}
```
