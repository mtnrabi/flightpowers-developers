## 2026-08-25 — developer site

`developers.flightpowers.com` goes up: home, `/flights-api`, `/hotels-api`, and this page.
Every page is rendered to static HTML at build time. The sitemap is generated by walking the
route tree, so a new page is announced to search engines the moment it exists — the previous
sitemap on `flightpowers.com` was a hand-maintained file and had gone stale.

Nothing about the APIs themselves changed in this entry.
